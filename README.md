# QA Portfolio

- **Manual Testing** — Test cases for e-commerce login and form validation. [`manual-testing`](./manual-testing)
- **Bug Reports** — Real defects found during testing the Noon website. [`bug-reports`](./bug-reports)
- **Automation** — Selenium framework using POM + TestNG to test login functionality. [`noon-login-automation-framework`](./noon-login-automation-framework)
- **API Testing** — Automated REST API test suite (Postman + Newman) for the Restful-Booker API, covering CRUD operations, token authentication, and negative/edge-case scenarios. Integrated with GitHub Actions for CI on every push.
